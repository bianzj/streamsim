## 2. 两阶段模拟产出

### 2.1 物理过程求解

主要产出是与三角面一一对应的三维物理量：

- 辐射度 `radiosity`
- 直射光增强 `lightEnhancement`
- 日照比例 `sunlit`
- 每个面元包含正、反两侧数值
- 可见性图统计、迭代次数和分阶段耗时

直接查看：在 StreamSim 中打开本工程，点击“模拟结果”，再打开 `radiosity_gpu.json`。界面以 Three.js 显示真实三维面元，可切换字段及正面、背面、平均值、最大值；点击任意面元可查看面元编号、对象、实例、Mesh、正反面数值与中心坐标。

### 2.2 成像模拟

主要产出是传感器视角的二维 ENVI 影像：

- `*.hdr`：影像尺寸、波段和数据类型
- `*.img`：32 位浮点像元数据
- 结果窗口可切换波段、显示伪彩色并查验 MIN/MAX
