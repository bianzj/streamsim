# 常用光谱示例

这些文件用于快速建模和接口测试，不代替现场或实验室测量光谱。

导入位置：`材质属性 → 光谱来源 → 导入波谱 TXT`。

文件格式：

1. 第一行：波长，单位 nm；
2. 第二行：反射率，范围 0–1；
3. 第三行：可选透射率，范围 0–1；
4. `#` 开头的内容为注释；
5. 热红外反射率和透射率仍在界面中单独填写，建议值见 `catalog.json`。

植被的正式研究优先使用界面内置 PROSPECT 预设，或导入实测光谱。土壤可使用 BSM 预设，或导入与含水量匹配的实测光谱。

界面默认仅提供一套“太阳能板光谱”，可后续修改参数或导入实测光谱。原单晶硅、多晶硅和双面玻璃组件 TXT 文件保留以兼容旧工程，不再作为默认预设。组件实测结果受玻璃、减反膜、电池片、封装和老化状态影响，定量研究应替换为对应组件的实测光谱。
